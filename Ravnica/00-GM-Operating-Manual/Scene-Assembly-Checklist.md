# Scene Assembly Checklist

1. Place: precinct, vertical level, ownership, civic function.  
2. People: worker, resident, traveler, guild functionary, rival observer, guildless local.  
3. Pressure: infrastructure, debt, jurisdiction, food, land, research, crime, protest, labor, ecology, planar anomaly.  
4. No-PC outcome: write what happens in one hour.  
5. Secret: someone knows the obvious explanation is incomplete.  
6. Sensory anchors: smell, sound, vertical feature, background action.  
7. Exit vectors: legal, social, covert, violent, technical, economic, ecological.
