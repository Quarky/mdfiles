# Ravnica Setting & Faction Guide
Obsidian-ready campaign reference for MTGFoundry. Open **[[Ravnica - Home]]** as the entry note.

The folder is self-contained and deliberately contains no `.obsidian` configuration, so copying it into an existing vault will not overwrite that vault's settings.

Material is separated conceptually into canon/source-grounded lore, campaign material, synthesis, and original fiction.
