## SCENE 1G — THE JINTEKI BIOMETRIC LOCK (Insert during any clone-related discovery)

If Dante finds a Jinteki maintenance terminal, he notices something: the biometric lock is still active. It hasn't been overridden. Someone with Jinteki credentials has been using this terminal.

**The Terminal:**

| Element | Detail |
|---------|--------|
| **Status** | Active. Logged in. |
| **User** | Clone maintenance personnel—authorized. |
| **Access** | Full system access. |
| **Recent Activity** | Maintenance handshake frequency access. |

**What This Means:**
- Someone with Jinteki access is using the terminal
- They're accessing the maintenance handshake frequency
- They're communicating with other clones
- Kai is not the only one
