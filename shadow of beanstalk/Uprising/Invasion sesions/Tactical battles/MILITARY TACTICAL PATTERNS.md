## MILITARY TACTICAL PATTERNS

| Pattern | Purpose | Counter-Tactic |
|---------|---------|----------------|
| **Dynamic Drone Screen** | Provide advance intelligence | Move during the 90-second window |
| **Controlled Pair Advance** | Create a moving wall of firepower | Use maintenance routes to flank |
| **Compression Zone** | Force enemy into a killing field | Use the maintenance network to escape |
| **Sealed Suit Advantage** | Move through decompressed areas | Monitor oxygen levels, move early |
| **EWS Siege** | Degrade network advantage | Use hardwired connections, move fast |
| **Information Loophole** | Anticipate enemy moves | Use code words, limit information |
| **Extraction Point Trap** | Intercept enemy escape | Use unexpected routes |
