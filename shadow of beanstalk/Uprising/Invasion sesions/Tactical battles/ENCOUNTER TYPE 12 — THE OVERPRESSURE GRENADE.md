## ENCOUNTER TYPE 12 — THE OVERPRESSURE GRENADE

### Setup
The military uses a weapon that creates a sudden pressure wave without fragmentation. It's designed to disorient and damage without killing.

### The Tactical Pattern
1. **Grenade Deployment:** A trooper throws a grenade into the Loony position.
2. **Pressure Wave:** The grenade detonates, creating a sudden pressure wave that concusses anyone in the area.
3. **Advance:** The military advances while the Loonies are disoriented.

### Tactical Challenge

| Element | Description |
|---------|-------------|
| **Environment** | Enclosed space |
| **Enemy** | Fire Team (4 troopers) — Advancing after grenade |
| **Objective** | Survive the pressure wave, avoid capture, or counter-attack |

### Options

| Option | Description | Difficulty | Outcome |
|--------|-------------|------------|---------|
| **Dive for Cover** | Get behind something solid | Average | Reduces the pressure wave effect |
| **Brace** | Brace yourself for the impact | Hard | Reduces the effect |
| **Throw It Back** | If you see it coming, throw it back | Very Hard | Requires excellent reflexes; if successful, the military is affected instead |
| **Run** | Run away from the grenade | Average | You escape the blast radius |
| **Sealed Suit** | If you have a sealed suit, you're protected | Easy | The pressure wave doesn't affect you |

### NPC Actions

| NPC | Action | Effect |
|-----|--------|--------|
| **Mac** | Use himself as cover | Protects others from the pressure wave |
| **Sully** | Identify the grenade and warn the team | Gives others time to react |
| **Riker** | Use a sealed container as cover | Provides protection |
| **Maeko** | Run to a safe distance | Escapes the blast radius |

### Dialogue Moment

> SULLY: "Grenade! Incoming!"
>
> MAC: "Get behind me!"
>
> RIKER: "That's an overpressure grenade. It's not fragmentation. But the pressure wave will knock us down."
>
> MAEKO: "I'm going to run. I can make it to the next corridor."
