## ENCOUNTER TYPE 13 — THE MOBILE BREACH SHIELD

### Setup
The military uses a heavy shield to advance through a corridor. The shield provides cover for the troopers behind it.

### The Tactical Pattern
1. **Shield Advance:** The shield moves forward, providing cover for the troopers behind it.
2. **Suppression Fire:** The troopers behind the shield fire over or around it, suppressing the Loonies.
3. **Breach:** The shield reaches the Loony position. The troopers breach and secure the area.

### Tactical Challenge

| Element | Description |
|---------|-------------|
| **Environment** | Corridor (3-4 meters wide) |
| **Enemy** | Fire Team (4 troopers) — 1 shield, 3 firing |
| **Objective** | Stop the shield advance, escape, or counter-attack |

### Options

| Option | Description | Difficulty | Outcome |
|--------|-------------|------------|---------|
| **Flank** | Move to a position where the shield doesn't provide cover | Average | The shield is useless if you're not in front of it |
| **High Ground** | Get above the shield | Hard | The shield doesn't protect from above |
| **Explosives** | Use explosives to destroy the shield | Very Hard | Requires anti-armor or heavy explosives; limited supply |
| **Fall Back** | Withdraw to a new position | Average | The military takes the ground, but you survive |
| **Wait** | Wait for the shield to reach you, then engage at close range | Hard | The shield is less useful at close range |

### NPC Actions

| NPC | Action | Effect |
|-----|--------|--------|
| **Sully** | Use the ventilation system to get above the shield | Provides a flanking position |
| **Junior** | Find an alternative route | Escapes the shield advance |
| **Riker** | Create a hazard (slick floor, debris) | Slows the shield advance |
| **Mac** | Meet the shield head-on | Engages the shield at close range |

### Dialogue Moment

> FLETCHER: "Shield! Heavy armor. They're advancing down the corridor."
>
> SULLY: "I can get above them. The ventilation shaft runs over this corridor."
>
> JUNIOR: "There's a maintenance hatch 20 meters back. We can escape that way."
>
> RIKER: "Or we can slow them down. I can create a slick floor with hydraulic fluid."
