## ENCOUNTER TYPE 5 — THE EXOSUIT INTERCEPTION

### Location Context
This encounter is specific to the crater rim surface. In Kaguya, it's the area between Ring 4 and the emergency airlocks.

### Setup
The squad is trying to reach a hopper on the surface. An exosuit pilot is patrolling the rim. The exosuit has a clear line of sight to the hopper. The squad needs to get past the exosuit to extract.

### The Challenge
| Element | Description |
|---------|-------------|
| **Environment** | Lunar surface, crater rim, open ground, no cover |
| **Enemy** | Exosuit Pilot (1). Heavy Gauss rifle. Slow-Firing 1. Breach 2. |
| **Objective** | Get past the exosuit to the hopper. |

### Tactical Options

| Option | Description | Difficulty | Outcome |
|--------|-------------|------------|---------|
| **Distract** | Create a distraction to draw the exosuit's attention | Hard | The exosuit moves away from the hopper |
| **Fight** | Engage the exosuit with anti-armor weapons | Daunting | Requires significant firepower. High risk. |
| **Wait** | Wait for the exosuit to move away | Very Hard | The exosuit is on patrol. It will eventually move. |
| **Use the Terrain** | Use the crater terrain to approach the hopper | Average | Requires navigation through rough terrain |

### NPC Actions

| NPC | Action | Effect |
|-----|--------|--------|
| **Maeko** | Drive the hopper | Gets the hopper off the surface |
| **Riker** | Override the exosuit's sensors | Temporarily blinds the exosuit |
| **Mac** | Create a distraction | Draws the exosuit's attention |
| **Sully** | Cut through the hopper's mooring | Prepares the hopper for extraction |

### Outcome
If the squad distracts the exosuit: The exosuit moves away. The squad reaches the hopper.
If the squad fights the exosuit: Casualties likely. The exosuit is very well-armored.
If the squad waits: The exosuit moves away. The squad reaches the hopper.
If the squad uses the terrain: The squad reaches the hopper without being seen.

### Dialogue Moment

> MAEKO: "The hopper is 200 meters away. The exosuit is between us and it."
>
> RIKER: "I can override his sensors. Temporarily. But he'll notice."
>
> FLETCHER: "We need 90 seconds. 90 seconds for Maeko to get to the hopper and start it."
>
> MAEKO: "90 seconds. I can do 90 seconds. Give me the distraction."
>
> MAC: (rebar club in hand) "I'll give him a distraction."
