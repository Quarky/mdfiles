## SECTION A — THE PRIMARY SERVER CORRIDOR

Four rows of server racks, each row twelve meters long, the racks 2.1 meters tall. The rows are numbered on the ceiling in stenciled white paint: ROWS 1 through 4, north to south. Row 1 is nearest the elevator. Row 4 is at the far end, against the southern rock wall.

The cold here has texture. It moves in currents produced by the cooling systems drawing heat away from the racks. Walking between rows, Dante encounters cold that shifts and eddies—warmer in one step and colder in the next. The racks generate heat but the cooling is so aggressive that heat is captured before it reaches the air.

The lighting is cold blue-white LEDs—the color temperature of efficiency. Each rack has its own indicator lights: green status, amber warning, red fault. At a glance: Row 1, all green. Row 2, mostly green, two amber. Row 3, all green. Row 4—VX-ARCHIVE-7 and neighbors—mostly green, with one rack showing an unusual light pattern.

### THE WIND TUNNEL — COLD HAZARD PUZZLE

The wind tunnel effect makes the server corridor colder than it would be if the air were still. The moving air pulls heat from exposed skin more quickly than still air would.

| Location | Temperature | Wind Chill Effect | Equivalent Temperature |
|----------|-------------|-------------------|------------------------|
| Under Supply (HVAC North) | -18°C | High | -26°C |
| Row 1-2 | -12°C | Moderate | -18°C |
| Row 2-3 | -10°C | Low | -14°C |
| Row 3-4 | -10°C | Low | -14°C |

**Time in Wind Tunnel:**

| Time | Effect |
|------|--------|

## NEW PUZZLES — HVAC AND WIND TUNNEL

### PUZZLE 1: TRACING THE HVAC PATH

The ductwork from the Cooling Plant to the server corridor is accessible. The supply grate can be removed. The ductwork leads from the Cooling Plant to the server corridor, passing through the HVAC Service Rooms.

| Approach | Difficulty | Outcome |
|----------|------------|---------|
| Remove the supply grate | Mechanics (Average) | Access the ductwork |
| Trace the ductwork path | Perception (Average) | The ductwork goes through the HVAC Service Room |
| Find the HVAC Service Room | Perception (Easy) | The side door is visible in the Cooling Plant |
| Access the dampers | Mechanics (Average) | Open or close the HVAC dampers |

### PUZZLE 2: CHANGING THE AIRFLOW

The HVAC Control Panel in the Cooling Plant allows Dante to adjust the airflow.

| Action | Outcome |
|--------|---------|
| Increase airflow | Server corridor gets colder. Makes the environment more hostile. |
| Decrease airflow | Server corridor gets warmer. Makes the environment more survivable. |
| Close the dampers | Stops airflow. Server corridor warms to -4°C over 30 minutes. |
| Open the dampers fully | Increases airflow. Server corridor cools to -14°C. |

### PUZZLE 3: THE DUCTWORK CRAWL

The ductwork can be used as a secondary access route. It connects the Cooling Plant to the server corridor, bypassing the pressure doors.

| Approach | Difficulty | Outcome |
|----------|------------|---------|
| Enter the ductwork | Athletics (Average) | Move through the ductwork |
| Navigate the ductwork | Perception (Hard) | Find the correct branch |
| Exit at the server corridor | — | Bypass the pressure door |

### PUZZLE 4: THE WIND TUNNEL AS SECURITY

The airflow can be used to detect movement. If Dante moves through the server corridor, he displaces air. The HVAC system will register the change in airflow.

| Action | Outcome |
|--------|---------|
| Move through the server corridor | HVAC system registers the displacement |
| Stand still | No displacement |
| Enter the ductwork | HVAC system does not register movement in the ductwork |

### PUZZLE 5: THE HVAC SERVICE ROOMS

The HVAC Service Rooms contain damper controls. Adjusting the dampers changes the airflow.

| Action | Outcome |
|--------|---------|
| Close the supply dampers | Reduces cold air entering the server corridor |
| Close the return dampers | Reduces warm air leaving the server corridor |
| Open the supply dampers | Increases cold air entering the server corridor |
| Open the return dampers | Increases warm air leaving the server corridor |
