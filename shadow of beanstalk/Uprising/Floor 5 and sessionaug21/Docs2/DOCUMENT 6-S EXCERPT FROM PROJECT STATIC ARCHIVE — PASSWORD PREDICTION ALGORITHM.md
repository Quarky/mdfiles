**PROJECT STATIC — APPENDIX D: PSYCHOGRAPHIC PASSWORD PREDICTION ALGORITHM**

---

**OVERVIEW:**

The psychographic password prediction algorithm was developed to compromise legacy Internet infrastructure during Project Static deployment. The algorithm utilizes behavioral data collected from users to predict credential selection patterns.

---

**METHODOLOGY:**

The algorithm employs the following approach:

1. **Data collection:** Behavioral data aggregated from 18 months of pre-deployment monitoring
2. **Pattern identification:** Identification of cognitive shortcuts used in credential selection
3. **Prediction:** Correlation of behavioral markers with specific credential choices

---

**BEHAVIORAL MARKERS USED FOR PREDICTION:**

| Marker Type | Examples | Prediction Weight |
|-------------|----------|-------------------|
| Family names | Spouse, children, parents | High |
| Significant dates | Birthdays, anniversaries | High |
| Emotional safety words | "Love," "home," "safe" | Medium |
| Pet names | Common pet names | Medium |
| Pattern sequences | "12345," "abc123" | Low |
| Device/hardware defaults | "admin," "password" | Low |

---

**PERFORMANCE DATA:**

| Dataset | Accuracy | Notes |
|---------|----------|-------|
| Baseline (pre-18 months) | 23.4% | No behavioral data |
| Pre-deployment (18 months) | 89.3% | Full behavioral dataset |

---

**NOTES ON LIMITATIONS:**

- The algorithm was trained on behavioral data from the pre-Blackout population
- Applicability to current populations requires ongoing calibration
- Specific population segments (runners, off-gridders) are underrepresented in training data
- Prediction accuracy for these segments is significantly lower
