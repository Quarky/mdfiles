# Beanstalk Network GM Set

This is a GM-facing Markdown reference and encounter set for structured Network scenes. It consolidates the Network chapter of *Shadow of the Beanstalk*, the relevant setting context from *The Worlds of Android*, and the behavior of the current Genesys Beanstalk Network Builder v0.5.2. Text is paraphrased for table use rather than reproduced as a replacement for either sourcebook.

## Navigation and autosplitting

- **H1** always marks one complete journal-sized entry: a rule reference, network, encounter, NPC dossier, or GM tool.
- **H2** marks a directly linkable subsection or node inside that journal.
- Split on **H1 only** to create one Foundry Journal per entry while preserving H2 anchors as internal links.
- The material is GM-side by default. Player-facing text is explicitly labeled.

## Folder index

1. `01_RULES` — source coverage, setting context, complete procedure, symbol spends, ICE, icebreakers, hardware, encounter construction, and module/campaign rulings.
2. `02_NETWORK_NPCS` — runners and sysops ready for Network encounters.
3. `03_EXAMPLE_NETWORKS` — complete node-by-node networks with topology, security, commands, reveals, and escalation.
4. `04_COMPLETE_RUNS` — staged encounters using those networks, including physical parallel scenes and fail-forward outcomes.
5. `05_GM_TOOLS` — run worksheet, clocks, quick tables, and session logging.
6. `06_FOUNDRY_JSON` — compatible topology imports matched to the Kaguya network dossiers.

## Source and rules priority

When details conflict, use this order:

1. Campaign rulings and explicit player/GM corrections.
2. The current Network Builder behavior described in `01_RULES/05_MODULE_WORKFLOW_AND_CAMPAIGN_OPTIONS.md`.
3. Published *Shadow of the Beanstalk* Network rules.
4. Setting material from *The Worlds of Android*.
5. Scenario-specific guidance in this set.

## Start here at the table

- Open `01_RULES/01_NETWORK_RULES_COMPLETE.md` for adjudication.
- Open `01_RULES/02_NETWORK_QUICK_REFERENCE.md` during play.
- Pick a network from `03_EXAMPLE_NETWORKS`.
- Run its paired encounter from `04_COMPLETE_RUNS`, or use the network as a reusable location.
- Record the result with `05_GM_TOOLS/01_RUN_WORKSHEET_AND_CLOCKS.md`.
