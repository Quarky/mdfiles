# Network Run — Silent Occupation

**Network:** [SXC Occupation Tactical Network](../03_EXAMPLE_NETWORKS/02_SXC_OCCUPATION_TACTICAL.md)  
**Length:** 60–90 minutes  
**Objective:** Clear a checkpoint and obtain signed occupation orders  
**Opposition:** Lieutenant Mara Venn, elite signals officer; two patrol minion groups  
**Core choice:** Quiet extraction versus public proof.

## Situation

SXC has detained civilians behind a portable checkpoint. A local organizer can move them if the scanner and challenge code are neutralized. The organizer also wants the signed order proving the sweep was planned before the reported emergency.

Required outcomes:

- **Extraction:** Mark one lane cleared or disable its scanner.
- **Evidence:** Copy signed pre-event orders.

Optional outcome: obtain a stand-down token from Command Authority.

## Access routes

The Tactical Mesh begins at Daunting and meets Hawk’s Eye. The relay jack is Hard and within sight of one patrol. The armory rack enters behind the sentry but requires a physical breach. The command console is easiest digitally and hardest physically.

If the team steals an officer’s active device, Access System is Hard and the first failed identity check raises Alert by 2 instead of 1.

## Clocks

- **Alert 0–4** uses the network response clock.
- **Detainee Transfer 6:** Reduce by 1 at the end of every round after the first. At 0, the detainees begin moving; the team has two more rounds to stop or follow the transport.
- **Trace 0–4** is shared by defenders.

## Physical scene

Run the checkpoint and Network in one initiative. Non-runners can:

- create a distraction to add 1 Setback to the next Sweep;
- steal a challenge code, adding 1 Boost to the Checkpoint Control command;
- cut relay power, suppressing Mara for one round but severing the current runner unless they change links;
- escort detainees once the lane is cleared;
- capture an officer token that enables the alternate Command Authority solution.

## Mara Venn’s turn logic

Use the Sable-9 profile.

1. Hawk’s Eye or obvious command alerts Mara.
2. Sweep if the runner’s presence is only inferred.
3. Trace a confirmed runner until Trace 2.
4. Swordbreaker the strongest active icebreaker if the runner attacks Orders or Command Authority.
5. Reinforce Hadrian’s Wall as a maneuver when Orders is targeted.
6. Lockout at Trace 2+ if the detainees have not moved; otherwise prioritize spoof correction and physical dispatch.

## Evidence route

The Backbone reveals Orders but not the Audit Mirror. Hadrian’s Wall protects Orders. The Audit Mirror appears after any one of:

- reading Orders metadata;
- spending Triumph to scout;
- examining device-join records at Patrol Tracking;
- physically reading the label on the command rack.

One Great Wall may protect both Orders and Audit Mirror. This gives runners a strategic choice: break it once for both evidence sources, or enter Orders through an officer console and never expose the mirror.

## Command authenticity

A network command can move SXC forces for one round. A lasting stand-down requires one of:

- a signed Command Authority token;
- Orders signature copied and forged with Hard Computers (Hacking), costing an action;
- an officer coerced or deceived into confirming it.

Do not let one unsigned text message permanently control a trained military force.

## Janus at Command Authority

Reveal Janus’s STR 9 and catastrophic effect before the runner commits. Offer the officer-token route. If the runner chooses Janus anyway, treat that as a deliberate high-risk play, not a surprise punishment.

## Outcomes

- **Extraction and proof:** Detainees escape and the team gains authenticated orders.
- **Extraction only:** Lives are saved; SXC controls the public story.
- **Proof only:** The evidence survives, but the transfer creates a rescue obligation.
- **Stand-down:** Immediate area de-escalates, but central command invalidates the token after the encounter unless Triumph made it persistent.
- **Lockout:** The armory rack contains a removable audit module; a physical character can take it, turning escape into the final objective.

## Carry-forward state

Record which SXC unit was embarrassed, whether Mara learned the runner’s signature, whether Janus was encountered, evidence authenticity, and the detainees’ destination.
