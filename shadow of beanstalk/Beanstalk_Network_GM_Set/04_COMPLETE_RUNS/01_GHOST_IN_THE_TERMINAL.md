# Network Run — Ghost in the Terminal

**Network:** [Kaguya Public Terminal Operations](../03_EXAMPLE_NETWORKS/01_KAGUYA_PUBLIC_TERMINAL.md)  
**Length:** 45–75 minutes  
**Objective:** Recover suppressed breach footage and open a civilian escape path  
**Opposition:** Arun Vale, Corporate Sysop; checkpoint security in the physical scene  
**Core choice:** Use the crowd as cover or spend time protecting it.

## Briefing

A decompression injured dozens in the public terminal. The official timeline begins forty-three seconds after the first pressure alarm. A station cleaner claims the missing interval showed a security bulkhead closing on an occupied corridor. The evidence cache still exists but will be purged at shift change.

The runners need two outcomes:

1. Download the Breach Incident Cache.
2. Open a service door before the next checkpoint sweep.

Completing only one is still useful; choosing which one matters.

## Opening access choice

Present all four access points. State the risk honestly.

- Wireless is immediate but monitored.
- Terminal jack is safer digitally but requires opening a kiosk in public.
- Ceiling service port bypasses casual observation but needs Athletics/Coordination and a spotter.
- Supervisor console gives the best route but sits behind a staffed checkpoint.

Let the non-runner create the access opportunity with Stealth, Deception, Mechanics, or social leverage. Success grants 1 Boost on Access System; Triumph enters at the Gateway rather than the Edge Router.

## Encounter start

Start one initiative order when the runner connects or when checkpoint staff become suspicious. Set **Alert 0**, **Trace 0**, and **Purge 4**. At the end of each round after Alert reaches 2, reduce Purge by 1.

## Round pressure

| Round | Network | Physical terminal |
|---:|---|---|
| 1 | Access and perimeter ICE | Shift announcement; maintenance drone approaches the tampered access point. |
| 2 | Choose door, cameras, or manifest route | Checkpoint supervisor begins a casual ID sweep. |
| 3 | Hidden cache can be discovered through Cameras | Crowd thickens around a delayed departure. |
| 4 | Arun joins if alerted and begins Trace | Security closes one public lane. |
| 5+ | Purge and Lockout race | A two-person security team reaches the runner’s physical sector. |

## Arun Vale’s priorities

1. If unaware, do nothing beyond routine monitoring.
2. At suspicion without a known intruder, Sweep.
3. When alerted, Trace.
4. Reinforce Syn 2.2 if the Credential Cache is attacked; otherwise reinforce Great Wall when the hidden cache is exposed.
5. At Trace 2 or more, attempt Lockout.
6. Arun never Burns a public terminal system; he is afraid of liability.

## Finding the hidden cache

The cache becomes visible through any one of these:

- Download or inspect recent camera routing.
- Spend Triumph to scout an unencountered node.
- Succeed at a Hard Knowledge (The Net) or Perception check while in Camera Control.
- Question Arun over a voice channel and win an opposed social check about the missing footage.

Do not gate the entire run behind this discovery. If the roll fails, reveal the route when Purge reaches 2, because the deletion process announces its destination.

## Commands with physical effects

- **Loop a camera:** Remove 1 Setback from allied Stealth for one round.
- **False gate change:** Move the crowd, creating concealment but delaying civilians.
- **Open service door:** Completes the escape objective.
- **Issue temporary credential:** A physical ally may cross the checkpoint once without a check.
- **Protect logs:** Freezes Purge at its current value while the command remains in force.
- **Download evidence:** Requires one command. A second command verifies the copy, preventing later claims of fabrication.

## Complications

- **Threat:** A camera turns toward the access point; add 1 Setback to the next physical cover check.
- **Three Threat:** The public announcement repeats the runner’s false gate information, creating a dangerous crowd surge.
- **Despair:** The footage contains the face of an ally or contact at the breach. The data is still valid.
- **Triumph:** The cache contains a second suppressed event linked to a future run.

## Success states

- **Clean success:** Evidence copied and route opened before Alert 3; no immediate pursuit.
- **Hot success:** Both objectives completed, but Trace or Alert identifies a likely runner location.
- **Partial success:** One objective completed. The other becomes a future favor, rescue, or public-relations consequence.
- **Lockout:** The physical team can still seize the local incident buffer from the supervisor console, requiring a Hard Skulduggery or Mechanics check under pressure.
- **Purge reaches 0:** The cache is erased from the terminal but mirrored for three minutes in the Audit queue; reveal a one-use route to the SXC Tactical Audit Mirror.

## Rewards and carry-forward state

Record evidence integrity, terminal Alert, traces, any copied credential, whether Arun saw the runner’s style, and whether civilians were endangered. The evidence is leverage, not automatic justice.
