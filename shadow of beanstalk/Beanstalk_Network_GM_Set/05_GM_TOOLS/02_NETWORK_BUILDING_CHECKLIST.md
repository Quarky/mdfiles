# GM Tool — Build a Network Encounter

## Define the dramatic job

Write one sentence containing a verb and consequence: “Copy the orders before the detainees move,” not “hack the military network.” Give the physical team something that changes access, time, or safety.

## Choose scope

- Use a simple encounter for one task and one check.
- Use a structured network when routes, ICE layers, trace pressure, or multiple commands are interesting.
- Use two linked networks only when authority genuinely differs, as with local pad operations and final flight clearance.

## Build the topology

1. Add 2–4 access points with different physical risks.
2. Add one perimeter monitor or identity gate.
3. Add a central bus/backbone.
4. Add 3–6 functional nodes that matter now.
5. Add one hidden evidence or authority node.
6. Give each node concrete commands.
7. State explicit limits.

## Place ICE

- One layer on each important node.
- One key node may have two layers for starting PCs.
- Default to barriers; include at least one sentry or code gate.
- Use sentries where discovery matters and code gates where ejection/re-entry matters.
- Telegraph Janus, Sagittarius A*, or any effect that can destroy a rig, brain, or system.

## Add a defender

Choose their skill, awareness, objective, and turn logic. A good sysop does not automatically know the runner is present. Give them a reason not to shut down the system immediately.

## Add clocks

Use no more than three active clocks. Recommended:

- Alert 0–4.
- Trace 0–4.
- Objective 6–0 or Hazard 0–4.

Every clock change must alter the fiction.

## Prepare reveals

Separate:

- what appears after Access System;
- what appears on selecting a node;
- what appears when ICE is encountered;
- what requires a command or symbol spend;
- what remains GM-only.

## Verify action economy

Walk through the shortest valid route. Count actions and maneuvers. Confirm the objective can be reached before the countdown only if the team makes meaningful progress. Include at least one longer, safer route and one shorter, riskier route.

## Finish with persistence

Decide what survives the scene: traces, back doors, logs, credentials, damaged programs, altered physical systems, witnesses, and faction reactions.
