## Layering guidance

- Put information-gathering or alert ICE before the barrier when you want a trace race.
- Put a code gate before a barrier when re-entry pressure matters.
- Put sentry after a barrier when the cost is paid only by runners committed to the objective.
- Use Janus only when its danger has been signaled and the objective justifies it.
- Great Wall should create a strategic choice among several partitions, not function as three unrelated copies.

## Custom ICE template

Record: **name, type, strength, blocking state, failure effect, special timing, visibility, protected node, and automation**. Start from a published strength band before adding a novel effect. A custom ICE should usually do one memorable thing, not combine ejection, trace, damage, and destruction at once.
