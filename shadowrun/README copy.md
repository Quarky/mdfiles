# Shadowrun Genesys — Matrix / Network GM Set

This set is for the Renraku Arcology campaign and uses **Paul M. N. Haakonsen's Shadowrun GENESYS conversion as the rules authority**. It is not Shadow of the Beanstalk and does not use Beanstalk's Access/ICE framework.

## Source policy

- Mechanics, action names, difficulties, damage, Matrix terminology, cyberware and programs: Haakonsen's supplied Shadowrun GENESYS document.
- Renraku Arcology, 2059 events, locations, NPC identities and missing equipment themes: the supplied Shutdown/3.5e-era material and the campaign documents.
- When a 3.5e item has no Haakonsen entry, this set preserves its theme and converts it into Genesys dice, ranks, encumbrance, rarity, price and qualities. It does not copy sourcebook prose.
- Existing Foundry items should be referenced by compendium name/UUID during import; this set does not silently create a second incompatible rules engine.

## Organization

Each H1 is safe to split into a separate journal or file. H2 headings are intended as linkable locations, nodes, or procedures inside that entry.

- `01_RULES/` — Haakonsen Matrix rules and quick procedures.
- `02_NETWORKS/` — complete Arcology networks with nodes, access paths and escalation.
- `03_RUNS/` — ready-to-run Matrix jobs.
- `04_GM_TOOLS/` — clocks, opposition and conversion notes.

The old `Beanstalk_Network_GM_Set` is retained as history only and should not be imported for this campaign.
