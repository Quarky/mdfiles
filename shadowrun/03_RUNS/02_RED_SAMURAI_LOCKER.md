# Network Run — Red Samurai Locker

## Brief

The team needs a medical kit, passkey or evidence from a Security Checkpoint WAN while the arcology lockdown is still being described as a temporary systems fault.

## Route

Physical checkpoint → local camera device → Security Checkpoint WAN → locker file/device → physical retrieval. A direct cable to a checkpoint device removes grid/noise penalties, but exposes the hacker to anyone touching the cable.

## Scene beats

### Cameras

Matrix Perception identifies the camera PAN and its master commlink. Edit File can loop a single angle; each additional angle is a new Action. A failed attempt adds Trace.

### Checkpoint host

Base access is Formidable. Use Firewall 3, Gate 2 and Sentry 2. The defender is an off-site Renraku spider whose first priority is to preserve the lockdown, not kill the runners.

### Locker device

With three marks, Jump into Rigged Device is possible only if the locker or drone has the needed adaptation; otherwise use Enact Command to unlock it. Physical retrieval is a Coordination or Skulduggery challenge while the hacker maintains access.

## Failure pressure

At Trace 3, a Red Samurai patrol is routed to the checkpoint. At Trace 5, the spider Expels User and the patrol arrives with the locker sealed. Keep the Network Action and physical action in the same initiative order so both sides matter.
