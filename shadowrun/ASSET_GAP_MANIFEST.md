# Asset and Add-on Module Manifest

## Required assets

No new map, NPC actor, adversary actor, item, portrait, or token is required to run Sessions 1 and 2 as written.

The guides deliberately use actors and scenes already present in the current Shutdown and Renraku Arcology map modules:

- Angie, Frank Crodler, Hidoshi Tarada, Mina Ortega, Evan Cho, and the Amber Voice;
- Dr. Sora Kwan, Marisol Vance, Niko Adebayo, Abena Cole, Priya Das, Eli Mercer, Lark, Farah Al-Masri, and Lian Santos;
- Greyline Crew members Zora “Jinx” Vega, Rook Kessler, Dara “Switchback” Okoye, and Tamsin “Moth” Saran;
- Renraku Security Drone, Maintenance Spider, Red Samurai, Blue Banded Enforcer, White Banded Otaku, and Doll Construct;
- all twelve Shutdown campaign scenes and all forty-eight RA map-pack scenes.

Generic residents, patients, workers, and children are narrative roles rather than required actors. If the table needs tokens, reuse a neutral civilian token without creating misleading named dossiers.

## Existing items and handouts used

- `7G_ANOMALY.log` — already present as a handout.
- Chameleon Suit — already part of Frank's build; its physical discovery occurs during Session 1.
- Respirators, maintenance credentials, medical supplies, tools, and drone parts — use existing equipment or narrative inventory.

## Optional additions for a later content module

These are useful but not required:

| Food Court charter | Revealable Journal handout | Records agreements from Encounter 17 |
| Greyline temporary contract | Revealable Journal handout | Records the exact Session 2 bargain |
| Local radio protocol | Item or Journal | Represents the Session 2 communications reward |

## Recommended next packaging step

If these optional elements are wanted, create a small **Shutdown Living World Add-on** module that depends on the existing Shutdown campaign and map modules. It should add journals, handouts, tracker macros, and optional actor variants without replacing established PCs, NPCs, scenes, or their artwork.

The Markdown in this pack can also be imported directly as GM-only journals. Files designed for autosplitting use H1 boundaries.
