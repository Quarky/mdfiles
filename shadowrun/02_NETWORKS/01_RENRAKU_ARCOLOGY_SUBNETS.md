# Renraku Arcology Shutdown — Network Topologies

These are campaign networks, not Beanstalk-style “systems.” Each node is a host or device cluster with a physical counterpart. Start at the node the runners can reach; do not require a single canonical route.

## Maintenance and Life-Safety WAN

### Node 1 — Maintenance Node 7-G

Public-facing service controls; Angie’s first-contact residue and Frank’s `7G_ANOMALY.log`. Base access: Hard local hub. Programs: Gate 2, Sentry 2.

### Node 2 — Clinic Triage Host

Medical records, doors, med-drones and patient telemetry. Base access: Hard. A successful Matrix Perception identifies which alarms are real and which are looped. Physical consequence: a wrong Enact Command seals a clinic door and dispatches a drone.

### Node 3 — Residential Evacuation Host

Elevator permissions, floor announcements and resident registries. Base access: Average common computer once a maintenance mark is acquired; otherwise Daunting regional hub. A defender is a cautious Renraku spider, not an automatic combat encounter.

### Node 4 — Security Checkpoint WAN

Razorwire doors, camera feeds, weapon lockers and patrol drones. Base access: Formidable corporate network. Firewall 3, Sentry 2, Gate 2. Being inside the host gives direct connection to slaved devices, but a failed Sentry override starts the trace clock.

### Node 5 — Amber Backdoor

Hidden host sculpted as a dark clinic corridor with amber diagnostic light. It is not a new rules subsystem: resolve it with Matrix Perception, marks, normal Matrix Actions and the narrative facts established by the campaign. The GM may permit Angie’s technomancer/otaku feature to create a story route, but do not bypass Computers tests without the character’s actual ability.

## Escalation clocks

- **Trace (0–5):** add one segment on failed Sentry/Gate attempts, obvious Brute Force, or a despair result. At 3, security identifies the host; at 5, a spider or G-men response arrives.
- **Life safety (0–4):** add one when the team delays while residents are trapped. At 4, a physical hazard changes the scene.
- **Anomaly attention (0–4):** add when the team asks the amber host questions or uses hot-sim. At 4, the hidden intelligence answers through an NPC, device, or sensory bleed.
