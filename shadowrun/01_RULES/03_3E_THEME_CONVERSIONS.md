# 3.5e Theme Gaps — Genesys Conversion Register

This register is deliberately short and explicit. It is used only when the Haakonsen document has no exact entry; an exact Haakonsen item always wins.

## Maglock passkey / sequencer

**Theme source:** Shadowrun 3.5e-style electronic entry tool.  
**Genesys conversion:** handheld tool, Encumbrance 0, rarity and price set by the campaign economy. Once per scene, before a Skulduggery or Computers check against a maglock, reduce the lock's difficulty one step; a Despair triggers the lock's alarm. It does not grant a mark and does not replace Access System in a Matrix encounter.

## Chameleon / ruthenium coating

**Theme source:** 3.5e adaptive camouflage.  
**Genesys conversion:** worn armor/clothing quality. Add one boost to Stealth in visual cover. In bright, featureless light the GM may remove the boost; it never makes the wearer invisible and never changes Matrix visibility.

## Security spider console

**Theme source:** 3.5e corporate security workstation.  
**Genesys conversion:** physical device slaved to the Checkpoint WAN. Direct connection ignores grid/noise penalties, but a failed Computers check alerts the console's owner. Use the Haakonsen Access System table and Matrix Actions for all intrusion effects.

## Custom program flag

If a Foundry item is marked as a program, it may be activated as a Matrix Action. The item must state its Action, check, duration and effect. Activation is never an automatic success; an active security program can block it exactly as it blocks the corresponding Haakonsen Action.
