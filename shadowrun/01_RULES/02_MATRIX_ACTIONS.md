# Matrix Actions — Haakonsen Procedure Card

Unless noted, these are Actions in a structured Matrix encounter. If a security program is active, actions marked “no active security” are unavailable until the program is disabled.

| Action | Difficulty / opposition | Use |
|---|---|---|
| Access System | Simple or system table | Establish access; required before other actions. |
| Activate Security Program | Average | Defender or intruder turns a known program on. |
| Brute Force | Hard | Place a mark without permission; may inflict 1 unsoakable Matrix damage per extra success. Two marks add two setback; three upgrades difficulty. Also forces an unpermitted grid hop. |
| Change Icon | None for self; opposed Computers for another | Alter appearance, not what Matrix Perception reveals. |
| Crash Program | Average | End one non-security running program until reboot. |
| Data Spike | Average | Matrix damage: Computers ranks + one per success + one per mark; soak with Computers. |
| Disable Security Program | Computers; variable | Need successes equal to program Strength. |
| Disarm Data Bomb | Opposed Computers | Remove a detected bomb; failure detonates it. |
| Edit File | Opposed Computers | Create, copy, alter, delete or protect one file detail per Action. |
| Enact Command | Computers; GM sets | One command within the system's intended scope. |
| Erase Mark | Hard | Requires three marks on the icon; can clear multiple with penalties. |
| Expel User | Opposed Computers | Remove another user; identified targets take two difficulty upgrades to regain access. |
| Full Matrix Defense | Special | Upgrade all incoming Computers checks until the start of your next turn. |
| Garbage In/Garbage Out | Hard | Cross one device input to one output; reboot restores it. |
| Grid Hop | None with access | Move to an accessible grid; otherwise use Brute Force or Access System. |
| Hide | Opposed Computers | Lose a target's awareness; impossible against an icon with a mark on you. |
| Invite Mark | Simple | Owner offers marks with chosen duration/limit. |
| Jack Out | Opposed Computers if link-locked | Reboot your device; VR causes dumpshock. |
| Jump into Rigged Device | Average | Requires VR, control rig, rigger adaptation and three marks (or owner permission). |
| Lockdown | Hard | Shut down the system for all users; restart takes one hour and Average Computers. |
| Matrix Perception | Simple; opposed if silent | Find/analyze icons. Each success asks one question; advantage reveals extra useful detail. |
| Matrix Search | Table below | Search time depends on availability. Advantages reveal useful information. |
| Send Message | None | Short text/audio/image/file; DNI permits a longer paragraph/live feed. |

## Matrix Search

| Information | Difficulty | Base time |
|---|---|---:|
| General / public | Easy | 1 minute |
| Limited or unpublicized | Hard | 30 minutes |
| Hidden / actively erased | Formidable | 12 hours |
| Protected or secret | Impossible | — |

Intricate information adds setback; specialized information adds two setback; another grid upgrades once. Extra successes reduce time by 10% each.
