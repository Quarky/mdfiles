# START HERE — Moraband Living World

This package separates **session-time story** from **preparation material**. The six files in `Sessions` are continuous GM walkthroughs with openings, developing events, descriptions, NPC conversations, complications, decisions, transitions, alternate routes, and endings. Start there during play.

The earlier overviews, clocks, encounter frameworks, map notes, and scene toolkits remain available under `Prep`. They are useful before a session or when the party leaves the default story route, but they are not intended to replace the playable narrative.

## Run order

1. Open [[Moraband Full Session Walkthrough GM Master]] or the next file in `Sessions`.
2. Run the story directly from that walkthrough, adapting it to player choices.
3. Consult `Prep/Scene Toolkits` only for extra mechanical, map, clue, or branch detail.
4. Consult `Prep/Campaign Prep` between sessions for clocks, continuity, Warde’s social arc, and handout timing.
5. Treat every map as optional support. The story continues when a map is skipped.

## Folder purpose

- **Sessions:** the actual GM-side adventure in playable order.
- **Prep/Campaign Prep:** campaign state, clocks, cast, travel, encounters, handouts, and finale options.
- **Prep/Scene Toolkits:** detailed modular support for individual locations and complications.
- **Prep/Session Outlines:** the earlier concise session structures, retained as quick planning aids.
- **Prep/Moraband Full Living World PREP Master:** combined preparation reference.

## Non-negotiable continuity

- Moraband follows Delriss and the separate Shard Moon adventure.
- Preserve ship strain/Critical Hits, companions, animals, injuries, Conflict, pursuer status, and recovered evidence.
- Sigg is an existing player character. Neither the Markdown nor Foundry module creates, imports, updates, or overwrites Sigg or any PC.
- Apply one automatic dark-side result whenever Force dice are rolled on Moraband.
- Failure changes condition, cost, position, or control; it never prevents the adventure from reaching Warde.
- Warn players before choices that award Conflict.
