# Converted Card Index

> [!warning] Incomplete inventory
> This index intentionally does not claim that every converted card has been enumerated. Individual card Markdown notes must be generated from actual current converted-card records, including their Foundry IDs and mechanical details.

## Required fields per card
- Card name and stable card ID
- Source set, printed mana cost, MV, colors, type, original rules text
- D&D access level, converted abilities, attack/save/damage, HP/AC if creature
- Permanent/temporary P/T and counters; typed damage and life loss
- Actions, reactions, tap/untap and timing
- Source version, implementation status, verification date

Do not treat printed MTG card text as evidence of a completed D&D conversion.
