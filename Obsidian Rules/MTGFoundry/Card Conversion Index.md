## How this index is built

- Card identities are matched by exact name against the saved Archidekt + Scryfall snapshot; Oracle IDs are retained for stable future refresh.
- Conversion payloads and implementation fields come from source-controlled Foundry Items/Actors, **not** inferred from printed Oracle text.
- Newer GitHub definitions or explicit user rulings supersede older rules checkpoints.
